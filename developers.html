01

把说明书交给你的 AI

下载 txt 说明书，上传或粘贴给你的 AI（ChatGPT、Claude、DeepSeek、豆包等都可以，它不需要联网）。然后告诉它你想要什么插件，它会按规范写出完整文件。

02

本地试用并自查

放进 %APPDATA%\Tianheluo\plugins\ 在 Revit 里试；运行 validate.py 自查（单文件，零依赖）。

宿主架构

简单、可读、可扩展

Revit 2026
 └─ THL.Host（外接程序，.NET 8 / .NET 10 两套编译，安装脚本自动选择）
     ├─ 功能区「天河落」：插件中心 + 已装插件按钮（最多 12 个）
     ├─ 插件管理器：%APPDATA%\Tianheluo\plugins\<id>\plugin.json
     ├─ 热加载：每次点击重新读取脚本/DLL，更新无需重启 Revit
     ├─ Python 运行环境：IronPython 3.4 + 标准库 + 精简 pyrevit 兼容层
     └─ 商店客户端：tianheluo.com/plugins.json → 下载 .thlp → 解压安装

插件包 .thlp

就是一个 zip：plugin.json + script.py（+ 可选图标）。可单独下载、单独更新、单独卸载。

Python 插件

用 Revit API 和少量与 pyRevit 同名的接口（revit、forms、script）。社区插件只收源码，便于审核。

安全优先

写模型必须单事务、先预览、可撤销；禁止执行外部程序、动态执行代码、未声明联网。详见规范第 9 节。
