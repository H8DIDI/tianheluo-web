清理重复松木桩垫层

测试版市政管线

扫描全项目里位置完全重叠的松木桩和垫层，先给出数量，确认后每处只保留一套，其余一键删除。

解决什么问题

在排管、井下面布置松木桩和垫层时，同一批构件被重复框选或重复运行，就会在原位置叠出第二套、第三套桩和垫层。重叠的图元肉眼几乎看不出来，却会让桩数和垫层体积的工程量成倍增加。

清理重复松木桩垫层会按位置比对整个项目：桩按坐标取整到 5mm 比较，垫层按外包框（10mm 容差）比较。每处位置保留一套，多出来的先给你列出数量，点确认后才会删除。

怎么用

  1. 打开项目，直接运行。不需要框选，插件会扫描整个项目。
  2. 弹窗会列出：重复重合的松木桩 N 根、重复的 DirectShape 垫层 N 块、重复的族垫层 N 块。如果提示“模型非常纯净”，说明没有重复。
  3. 点「确定」，每处位置只保留一套，其余删除；点「取消」则什么都不改。
  4. 完成后弹窗会给出删除数量。需要恢复可以按 Ctrl+Z（整个清理在同一个事务里）。

注意事项

  • 识别范围是结构基础类别里：类型名含「松木桩」或「Φ75」的桩；由天河落布置的垫层（DirectShape）或名称含「垫层」的垫层；名称含「井垫层」（如「市政_井垫层」）的族实例。其他构件不会被动。
  • 每处只保留最先找到的那一个，其余删除。删除前建议先保存项目。
  • 位置按 5mm / 10mm 取整比较：错位超过几毫米的“差不多重合”不会算重复；落在取整边界两侧的极少数重复也可能漏掉。
  • 新版 一键布置松木桩垫层 已内置防重复布置机制，这个插件主要用来清理历史遗留的重复图元。

怎么安装

推荐：在 Revit 里打开「天河落 → 插件中心 → 商店」，找到它点「安装」，立刻能用，不用重启。
也可以先点右边「下载插件」得到 .thlp 文件，再在插件中心点「安装插件包…」选择它。还没装宿主？先看 安装指南。
有新版本时，插件中心会提示「更新」，一键即可。
