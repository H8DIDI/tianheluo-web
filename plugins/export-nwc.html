一键导出NWC

已实测导出

一个窗口选好导出范围、坐标、是否带属性和保存位置，一键导出 Navisworks 的 .nwc；有进度条，默认不转换链接的 CAD 防卡死。

解决什么问题

把 Revit 模型交给 Navisworks 做碰撞检查、协调会或施工模拟，要走“导出 → NWC”，每次都要选导出范围、勾选转换选项，还常常因为链接的 CAD 底图而卡死，甚至崩溃。

一键导出NWC 把这些放进一个窗口：范围（当前三维视图 / 勾选多个三维视图 / 整个模型）、共享或内部坐标、是否连同链接模型、是否导出构件属性、保存位置，选一次就记住。导出时有进度条可取消，导完列出每个文件的大小和用时。

怎么用

  1. 在 Revit 的「天河落」选项卡里点击「一键导出NWC」，在窗口里选好范围和选项。
  2. 范围选「当前三维视图」时，建议先打开一个干净的 3D 视图并把不需要的内容隐藏，因为导出的就是这个视图里可见的内容；选「勾选多个」时每个视图导出一个 NWC。
  3. 点「开始导出」。模型大时每个文件可能要几分钟，进度条里可以取消（已导完的保留，剩下的不再导）。
  4. 导完弹窗列出每个文件的大小和用时，并打开文件夹。在 Navisworks 里打开或附加即可。

注意事项

  • 电脑上要装有 Navisworks 的 NWC 导出组件：在 Revit「附加模块 → 外部工具」里能看到 Navisworks 才行，否则插件会提示去安装。
  • 「导出构件属性」取消勾选后导出更快、文件更小，但 Navisworks 里查不到参数；碰撞检查通常需要属性，按需选择。
  • 「转换链接的 CAD」默认不勾：它是导出卡死或崩溃最常见的原因。
  • 同名文件会被覆盖，保存位置默认是桌面，可以在窗口里改，改了会记住。
  • 导出过程中 Revit 暂时没有响应是正常现象。这个插件只导出文件，不会修改模型。

功能

  • 一个窗口里选好范围、坐标、链接、是否带属性和保存位置（都会记住），带进度条可取消，导完列出每个文件的大小和用时。
  • 默认不转换链接的 CAD（最常见的卡死原因）。
  • 需要电脑上装有 Navisworks 导出插件（Navisworks NWC Export Utility）。

怎么安装

推荐：在 Revit 里打开「天河落 → 插件中心 → 商店」，找到它点「安装」，立刻能用，不用重启。
也可以先点右边「下载插件」得到 .thlp 文件，再在插件中心点「安装插件包…」选择它。还没装宿主？先看 安装指南。
有新版本时，插件中心会提示「更新」，一键即可。
