框选提量导出Excel（结构 + 井排管）

已实测结构与算量

框选构件即得混凝土、钢材、钢筋，以及小市政的井、排管导管、桩和垫层，带体积、表面积、长度、标高等施工用字段；场地道路绿化开挖这类楼板自动排除并列出，导出一个 Excel。

解决什么问题

算一片区域的工程量，往往要分别建混凝土、钢材、钢筋的明细表，小市政项目还要另外统计井、排管、桩和垫层，临时核个量也要折腾半天。

框选提量直接统计框选范围（或整个项目、当前视图）里的构件，按标签页给出表格：结构的混凝土体积、钢材重量、钢筋按直径汇总；小市政的井汇总与逐口明细、排管导管、桩与垫层。看完再决定是否导出。排管、松木桩、垫层各自单算，不会混进混凝土表。

怎么用

  1. 先选好构件，或直接点「框选提量导出Excel」后选「现在框选」，在视图里框出范围（也可以选整个项目、当前视图）。
  2. 窗口里按标签页看：混凝土、钢材、钢筋、井汇总、井明细、排管导管、桩与垫层、已排除（没有的不出现）。
  3. 需要留档时导出 Excel（xlsx，每个标签页一个工作表）；需要随模型更新时，在 Revit 里生成明细表。
  4. 构件很多时有进度条，可以随时取消。

注意事项

  • 只读统计，不改模型（生成明细表除外）。
  • 场地里的道路、绿化、开挖范围、遮罩、临时道路这类楼板不算结构混凝土：类型名含这些字，或楼板「结构」没勾选的，一律排除，并在「已排除」页列出类型、数量、体积、面积和原因，不会悄悄消失。规则在 文档\KaifaTools\提量排除规则.json（第一次运行自动生成，可改关键字，也可以关掉「非结构楼板」这条）。
  • 混凝土、钢材页：楼层、类别、类型、材质、数量、体积、表面积（模板面积参考）、长度或高度、最低和最高标高。
  • 排管页：根数、总长、平均单根长、孔数、孔·米、混凝土体积（包封量）、最低底标高、最高顶标高；井页：长宽、深度档、最小最大井深、井底标高、井盖面标高；桩与垫层页：体积、面积（体积÷厚度）、桩总长、标高范围。
  • 排管按族名认：以 TELCO、ELV、LV-、ELE-、雨水沟 开头，或名字里有「排管」「N孔」的结构框架；其余结构框架仍按梁算混凝土。孔·米 = 孔数 × 长度。
  • 钢材按材料密度判断（密度 ≥ 6000 kg/m³ 或材料名含「钢」）；钢筋统一按 7850 kg/m³ 计重。读不出体积的构件会跳过，并在结果里提示数量。
  • 本插件已合并原「排管井工程量表」，原插件不再单独提供。

功能

  • 结构：混凝土体积（m³）、钢材重量（t，按材料密度算）、钢筋按直径汇总（根数、总长、重量）；
  • 小市政：井按系列、族类型、深度档汇总并附逐口明细，排管和导管按族类型汇总根数、长度、孔数、孔·米，松木桩根数和垫层块数、体积。
  • 排管、松木桩、垫层各自单算，不会混进混凝土表。也可以在 Revit 里生成明细表（之后模型改了自动更新）。只读，不改模型（生成明细表除外）。

怎么安装

推荐：在 Revit 里打开「天河落 → 插件中心 → 商店」，找到它点「安装」，立刻能用，不用重启。
也可以先点右边「下载插件」得到 .thlp 文件，再在插件中心点「安装插件包…」选择它。还没装宿主？先看 安装指南。
有新版本时，插件中心会提示「更新」，一键即可。
