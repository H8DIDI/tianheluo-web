我们收集什么，不收集什么

天河落是公开共享、非商业的开源项目。下面说的每一条，都能在公开的网站源码和宿主源码里核对。最后更新：2026-10-18。

浏览网站时

  • 网站不设置 cookie，不使用广告，也不做跨站追踪。
  • 为了了解哪些页面有人看，网站使用 Cloudflare Web Analytics：它不使用 cookie、不识别具体个人，只给出页面浏览量、来源、浏览器和设备类型、大致地区这类汇总数据。
  • 网站托管在 Cloudflare。和任何网站一样，托管商会在传输过程中看到访问者的 IP 和请求，用于提供服务和防御攻击，这部分由 Cloudflare 按其隐私政策处理。我们自己记录的 IP 见下面两节。

下载计数、IP 与下载地区

插件商店的“下载次数”和热门榜，来自每次下载时的计数。每计入一次下载，同时记下：

  • 下载时间、插件名（宿主更新包记为 host）；
  • 访问者的 IP 地址，以及 Cloudflare 根据 IP 估算出的国家、省/州、城市和大致经纬度（城市级粗略位置，不是住址）。
  • 这些信息只用于站长分析和优化网站（例如了解哪些地区的人在用、排查异常下载），不出售，也不分享给任何第三方，网站上不展示。
  • 保留 180 天，到期整条记录（包括 IP）自动删除。
  • 同一访问者 1 小时内对同一插件只算一次，靠的是一个加盐哈希值（取 IP 网段、插件和时间段做哈希），约 2 天后自动清理。
  • 长期保存的只有“某插件某一天被下载了几次”。计数失败不会影响下载本身。

网站使用统计

为了改进搜索、商店和页面速度，网站会记录少量使用事件：

  • 搜索与商店：搜索了什么词、结果有几条，选了哪个分类或排序。
  • 点击：插件卡片、下载按钮、复制提示词、联系方式（邮箱、GitHub）。
  • 页面：打开了不存在的地址（404）、页面加载速度（LCP、CLS、TTFB），页面脚本报错。
  • 不设置 Cookie，不使用账号或设备标识。每个事件会同时记录访问 IP 和 Cloudflare 估算的国家、省/州、城市，再加上事件名、页面路径、数值，以及搜索词等一小段文字；其中的电话号码（7 位以上数字）和邮箱会先被遮盖。
  • 浏览器开启“请勿追踪”或 GPC（全局隐私控制）时，这些统计完全关闭。
  • 保留 180 天后整条记录（包括 IP）自动删除。只用于站长分析和改进网站，不向访客展示，不出售，也不分享给第三方。

Revit 里的宿主

  • 宿主只会向 tianheluo.com 读取商店清单（plugins.json）、宿主更新清单（host.json），以及在你点“安装 / 更新”时下载对应的插件包或更新包。
  • 宿主不会上传你的模型、项目文件、文件名或任何使用数据，没有遥测。
  • 插件包和更新包下载后会校验 SHA256，校验不通过不会安装。

你主动联系我们时

通过邮件或微信联系时，我们会看到你主动提供的信息（邮箱、微信号、你写的内容），只用来回复你、处理反馈和投稿，不会出售或转给第三方。想删除你发给我们的内容，发邮件说一声即可。
