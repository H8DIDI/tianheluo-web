使用指南

5 分钟用上天河落

不需要懂编程。照着下面三大步做，每一步都有说明。适用于 Windows + Revit 2026。

第一步　安装「宿主」（只装一次）

宿主就像一个“手机”，后面所有插件都是装在上面的“App”。

下载安装包

下载宿主安装包（约 14 MB）

解压

在下载的文件上点右键，选「全部解压缩」。不要直接在压缩包里双击运行，否则会失败。

先关闭 Revit，再双击 install.bat

看到「安装完成」就好了。如果提示 Revit 正在运行，关掉 Revit 再试一次。

打开 Revit 2026

顶部会多出一个「天河落」选项卡。第一次打开时 Revit 会弹出安全提示，选「始终加载」。

第二步　安装插件（想用什么装什么）

每个插件都可以单独下载，只装你需要的。

方法 A：在 Revit 里一键安装（推荐）

点「天河落」选项卡里的「插件中心」 → 切到「商店」 → 点插件右边的「安装」。装完立刻能用，不用重启 Revit。

方法 B：先下载文件，再导入

在 插件商店 里点「下载插件」，得到一个 .thlp 文件。然后在「插件中心」右下角点「安装插件包…」，选中这个文件即可。适合没有网络的电脑。

第三步　使用和管理插件

运行插件

打开「插件中心」，在搜索框输入名字（比如「井深」），按回车就运行；也可以点插件右边的「运行」。如果插件需要选东西（比如垫层松木桩要先选中井），请先在 Revit 里选好，再打开插件中心。

改错了怎么办

所有会修改模型的插件都只算「一次操作」，按一次 Ctrl + Z 就全部撤销。

更新插件

在「商店」页，如果插件有新版本，按钮会变成「更新到 vX.X.X」，点一下即可，同样不用重启。

停用或卸载

在「已安装」页，点插件右边的「停用」（先收起来不用）或「卸载」（彻底删除）。

提示：功能区「已装插件」栏里的快捷按钮，只在重启 Revit 后才会更新。但「插件中心」里永远是最新的，平时用它最方便。

常见问题

Revit 里没有「天河落」选项卡？

确认安装时 Revit 是关着的，并且装的是 Revit 2026。再运行一次install.bat，然后重新打开 Revit。

商店里显示「连接商店失败」？

检查网络。没有网络的话，用「方法 B」导入下载好的 .thlp 文件。

怎么更新宿主和插件？

不用回官网下载。打开 Revit 里的「天河落 → 插件中心」，它会自动检查：插件有新版本时，「已安装」页会出现「更新到 vX」按钮（也可以点底部「全部更新」），立刻生效，不用重启；宿主有新版本时，顶部会出现蓝色横幅，点「下载更新」，更新会先下载并校验，关闭 Revit 之后自动安装，下次打开就是新版。更新失败会自动回滚到旧版。

双击 install.bat 后窗口一闪就没了？

一般是没有把压缩包完整解压就直接在压缩包里运行了。请先右键压缩包选「全部解压缩」，再进入解压出来的文件夹双击 install.bat。如果还是不行，打开里面的 README.txt，按「手动安装」三步复制文件即可；并把 %TEMP% hl-install.log 发给我们。

第一次打开 Revit 时弹出“加载项安全”提示？

这是 Revit 对所有第三方插件的标准提示。天河落的发布者是 didi（tianheluo.com）。请选择「始终加载」，以后就不会再问。

Revit 提示“无法运行外部应用程序 天河落 THL”？

多半是 Revit 版本和安装的版本不匹配。安装脚本会按你的 Revit 版本自动选择：2026.5 及以上用 .NET 10 版，2026.0 ~ 2026.4 用 .NET 8 版。请用最新的安装包重新安装；如果仍然不行，把 %APPDATA%\Tianheluo\logs\startup.log 这个文件发给我们。

怎么卸载宿主？

关闭 Revit，双击安装包里的uninstall.bat。

支持其他 Revit 版本吗？

目前只支持 Revit 2026，其他版本会陆续适配。
