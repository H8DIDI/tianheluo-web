安装指南

三步用上天河落

适用于 Windows 与 Revit 2026。

安装宿主

下载宿主安装包并运行。宿主会把 .addin 清单放到 %AppData%\Autodesk\Revit\Addins\2026，程序文件放到同级的天河落文件夹。

下载插件

在 插件商店 选择需要的插件，点击「下载插件」，得到一个 .dll 文件。

放入 Plugins 并重启 Revit

把 .dll 复制到宿主目录下的 Plugins 文件夹，重新启动 Revit。选项卡里就会出现对应的按钮。

宿主安装包尚未公开发布，目前处于内测阶段。发布后这里会出现下载按钮；如需提前试用，请发邮件到 hello@tianheluo.com。

常见问题

Revit 提示是否信任该加载项？

首次加载会弹出安全提示，选择「始终加载」即可。

插件改了模型怎么回退？

所有会修改模型的插件都在单个事务里执行，按一次 Ctrl+Z 整体撤销。

支持其他 Revit 版本吗？

目前只支持 Revit 2026，其他版本会在后续陆续适配。
